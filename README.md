# 忆格

忆格是适配手机、平板和桌面浏览器的间隔记忆卡网站。页面无需安装 App；复习数据保存在当前浏览器的本地存储中，不经过服务端，也不会自动同步到其他设备。

## 使用

1. 打开 GitHub Pages 网站。
2. 第一次使用马克记牌组时，进入「备份」并点「从网站载入马克记牌组」。这会从同站点载入 100 张知识点卡和 2,199 道题，只需操作一次。知识点卡与选择题分开入组，例如「马原·知识点」是 36 张，「马原·选择题」另列。
3. 在「卡片」页搜索、筛选、编辑或删除单张卡片；「卡组」页可新建或删除卡组。
4. 卡片与复习进度保存在当前设备、当前浏览器。换设备或清除浏览器数据前，请导出 JSON 备份。

首次访问网站和载入牌组需要网络。复习数据保存在浏览器中；GitHub Pages 版没有配置离线缓存，断网后重新打开网页可能无法加载。
